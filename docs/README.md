# ChefEar STT Evaluation Results

ChefEar 음성 레시피 서비스에 적용하기 위해 개발한 STT 모델의 실험 및 평가 결과를 정리한 자료입니다.

Whisper Large-v3-turbo를 기반으로 요리 도메인 음성 데이터에 파인튜닝을 적용하고, Fixed100과 신규500 데이터셋을 통해 모델의 인식 성능과 일반화 성능을 평가했습니다.

| 파일 | 설명 |
|---|---|
| [result.ipynb](./result.ipynb) | 모델 실험 과정과 최종 평가 결과를 정리한 분석 노트북 |
| [ChefEar_STT_3model_comparison_final.csv](./ChefEar_STT_3model_comparison_final.csv) | 여러 STT 모델의 최종 비교 결과 |
| [final_evaluation_summary.csv](./final_evaluation_summary.csv) | 최종 평가 지표 요약 |

## 🧪 평가 기준

### Fixed100

고정된 100개 문장을 사용하여 모델의 기본적인 음성 인식 성능을 평가했습니다.

### 신규500

기존 학습 데이터와 겹치지 않는 신규 500개 문장을 사용하여 모델의 일반화 성능을 평가했습니다.

### 취약유형 평가

요리 음성 인식에서 오류가 발생하기 쉬운 다음 유형을 별도로 분석했습니다.

- 숫자·수량·단위
- 재료명
- 조리동작
- 받침 및 발음
- 긴 문장

### TTS 음성 재인식 평가

TTS가 생성한 음성을 다시 STT 모델에 입력하여 실제 음성 출력 환경에서의 인식 결과를 확인했습니다.

## 📊 최종 평가 결과

| 평가 지표 | 결과 |
|---|---:|
| Fixed100 WER | 7.68% |
| Fixed100 CER | 1.44% |
| 신규500 WER | 10.72% |
| 신규500 CER | 2.26% |
| 문장 전체 일치율 | 61.80% |
| 숫자·단위 인식 성공률 | 90.57% |

| 조리동작 인식 성공률 | 99.54% |
| 핵심정보 종합 성공률 | 96.23% |

> 핵심정보 종합 성공률은 숫자·단위, 재료명, 조리동작 인식 결과를 바탕으로 산출한 도메인 자체평가 지표입니다.

## 🔍 실험 및 개선 과정

모델 개발은 다음 순서로 진행했습니다.

```text
기반 모델 비교
→ 파인튜닝 설정 비교
→ Epoch별 일반화 성능 평가
→ 오류 유형 분석
→ 취약유형 데이터 보강
→ 숫자·단위 특화 실험
→ 일반 데이터와 보강 데이터 혼합학습
→ 최종 모델 선정
```

실험을 통해 다음 내용을 확인했습니다.

- 학습 설정에 따라 WER·CER 성능이 달라짐
- 학습 데이터의 양과 구성 개선이 전체 성능 향상에 영향을 줌
- 숫자·단위 데이터를 집중 보강하면 해당 유형의 인식 성능이 향상됨
- 특정 유형만 집중 학습할 경우 전체 문장 성능이 일부 변할 수 있음
- 일반 문장과 취약유형 데이터를 함께 학습하면 성능 균형을 개선할 수 있음

## 📈 결과 해석

최종 파인튜닝 모델은 신규500 기준으로 WER 10.72%, CER 2.26%를 기록했습니다.

특히 요리 서비스에서 중요한 재료명과 조리동작 인식에서 높은 성능을 확인했습니다.

- 재료명 인식 성공률: 98.31%
- 조리동작 인식 성공률: 99.54%
- 숫자·단위 인식 성공률: 90.57%

반면 문장 전체 일치율은 61.80%로, 문장 일부에 오류가 있더라도 요리 수행에 필요한 핵심 정보는 비교적 정확하게 인식하는 경향을 확인했습니다.

## 📏 평가 지표

### WER

단어 단위 오류율입니다. 값이 낮을수록 단어 수준에서 정답과 가까운 결과입니다.

### CER

문자 단위 오류율입니다. 한국어 음성 인식 결과의 세부적인 차이를 확인하는 데 사용했습니다.

### 문장 전체 일치율

예측 문장 전체가 정답과 완전히 일치한 비율입니다.

### 핵심정보 인식 성공률

요리 서비스에 필요한 재료명, 조리동작, 숫자·단위 등의 핵심 정보가 정확하게 인식되었는지를 평가한 지표입니다.

## ⚡ 배포용 모델 경량화

실시간 음성 인식을 위해 파인튜닝 모델을 경량화된 배포 형식으로 변환하여 faster-whisper 기반 추론 환경에 적용했습니다.

```text
파인튜닝 모델
→ 배포용 형식 변환
→ 경량화
→ 실시간 음성 인식
```

학습용 모델과 배포용 모델은 실행 목적에 따라 구분하여 관리합니다.
