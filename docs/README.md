# 📊 ChefEar STT 평가 결과

ChefEar STT 모델의 평가 결과와 모델 비교 자료를 정리한 폴더입니다.

상세한 모델 개발 과정은 `result.ipynb`에서 확인할 수 있으며, 이 README에서는 평가 기준과 최종 결과만 간결하게 정리합니다.

## 📁 파일 안내

| 파일 | 설명 |
|---|---|
| [result.ipynb](./result.ipynb) | 전체 모델 실험 및 최종 선정 과정 |
| [ChefEar_STT_3model_comparison_final.csv](./ChefEar_STT_3model_comparison_final.csv) | 비교 모델별 최종 결과 |
| [final_evaluation_summary.csv](./final_evaluation_summary.csv) | 최종 평가 지표 요약 |
| [fixed100_predictions.csv](./fixed100_predictions.csv) | Fixed100 문장별 예측 결과 |
| [new500_predictions.csv](./new500_predictions.csv) | 신규500 문장별 예측 결과 |

## 🧪 평가 기준

### Fixed100

고정된 100개 문장을 사용하여 모델의 기본적인 음성 인식 성능을 평가했습니다.

### 신규500

기존 학습 데이터와 겹치지 않는 신규 500개 문장을 사용하여 모델의 일반화 성능을 평가했습니다.

### 도메인 핵심정보 평가

요리 서비스에서 중요한 다음 항목을 별도로 평가했습니다.

- 숫자·수량·단위
- 재료명
- 조리동작
- 긴 문장
- 발음이 유사한 표현

### TTS 음성 재인식 평가

TTS가 생성한 음성을 다시 STT 모델에 입력하여 실제 음성 출력 환경에서의 인식 결과를 확인했습니다.

## 📈 최종 평가 결과

| 평가 지표 | 결과 |
|---|---:|
| Fixed100 WER | 7.68% |
| Fixed100 CER | 1.44% |
| 신규500 WER | 10.72% |
| 신규500 CER | 2.26% |
| 문장 전체 일치율 | 61.80% |
| 숫자·단위 인식 성공률 | 90.57% |
| 재료명 인식 성공률 | 98.31% |
| 조리동작 인식 성공률 | 99.54% |
| 핵심정보 종합 성공률 | 96.23% |

> 핵심정보 종합 성공률은 숫자·단위, 재료명, 조리동작 인식 결과를 기준으로 산출한 요리 도메인 자체평가 지표입니다.

## 🔍 결과 요약

- Fixed100 CER은 1.44%로 나타났습니다.
- 신규500 CER은 2.26%로, 새로운 문장에서도 안정적인 인식 성능을 확인했습니다.
- 재료명 인식 성공률은 98.31%였습니다.
- 조리동작 인식 성공률은 99.54%였습니다.
- 숫자·단위 인식 성공률은 90.57%였습니다.
- 문장 전체 일치율은 61.80%로, 긴 문장이나 복합 표현에서는 일부 오류가 확인되었습니다.

전체 성능뿐 아니라 요리 수행에 필요한 핵심정보 인식 결과를 함께 고려하여 최종 모델을 선정했습니다.

## 📏 평가 지표

- **WER**: 단어 단위 오류율
- **CER**: 문자 단위 오류율
- **문장 전체 일치율**: 예측 문장 전체가 정답과 일치한 비율
- **핵심정보 성공률**: 재료명, 조리동작, 숫자·단위의 인식 성공률

WER과 CER은 값이 낮을수록 좋으며, 인식 성공률과 문장 전체 일치율은 값이 높을수록 좋습니다.
