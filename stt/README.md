# 🔊 ChefEar STT

ChefEar 음성 레시피 서비스에 적용하기 위해 개발한 개인 STT 모델입니다.

Whisper 기반 음성 인식 모델을 요리 도메인에 맞게 파인튜닝하여, 요리명·재료명·수량·단위·조리동작과 같은 핵심 정보를 음성으로 인식할 수 있도록 개발했습니다.

## 🎯 개발 목표

요리 중 화면이나 키보드를 조작하기 어려운 상황에서도 다음 음성 정보를 안정적으로 인식하는 것을 목표로 했습니다.

- 요리명
- 재료명
- 수량과 계량 단위
- 조리동작
- 조리 단계 진행 명령
- 긴 조리 안내 문장

## 🧑‍💻 담당 업무

- Whisper Small, wav2vec2, Whisper Large-v3-turbo 비교
- Whisper Large-v3-turbo 기반 QLoRA 파인튜닝
- 요리 도메인 음성 데이터 전처리 및 학습
- Fixed100·신규500 기반 WER·CER 평가
- 숫자·수량·단위 취약유형 분석
- 재료명·조리동작·긴 문장 인식 분석
- 최종 STT 모델 선정
- TTS 음성의 STT 재인식 테스트
- 실시간 추론을 위한 모델 경량화

## 🧠 기반 모델 및 파인튜닝

여러 STT 모델을 비교한 결과, 한국어 음성 인식 성능과 요리 도메인 적용 가능성을 고려하여 Whisper Large-v3-turbo를 기반 모델로 선정했습니다.

이후 요리명, 재료명, 숫자, 단위, 조리동작 및 음성 명령이 포함된 데이터에 QLoRA 파인튜닝을 적용했습니다.

학습 과정에서는 평가 결과를 바탕으로 오류 유형을 분석하고, 숫자·수량·단위와 같은 취약유형 데이터를 보강했습니다.

## 🧪 평가 방법

### Fixed100

고정된 100개 문장을 사용하여 기본 음성 인식 성능을 평가했습니다.

### 신규500

학습에 사용하지 않은 신규 500개 문장을 사용하여 일반화 성능을 평가했습니다.

### 도메인 핵심정보 평가

요리 서비스에 필요한 다음 항목을 별도로 평가했습니다.

- 숫자·수량·단위
- 재료명
- 조리동작
- 긴 문장
- 발음이 유사한 표현

### TTS 재인식 테스트

TTS가 생성한 음성을 STT 모델에 다시 입력하여 실제 음성 출력 환경에서의 인식 결과를 확인했습니다.

```text
TTS 음성 생성
→ STT 재인식
→ 정답 문장 비교
→ WER·CER 측정
```

## ✅ 최종 모델 선정 기준

최종 모델은 WER 또는 CER 하나만으로 결정하지 않았습니다.

다음 항목을 종합하여 선정했습니다.

- Fixed100 성능
- 신규500 일반화 성능
- 숫자·수량·단위 인식
- 재료명 인식
- 조리동작 인식
- 긴 문장 처리
- 취약유형 보강 이후의 전체 성능
- 실시간 추론 적용 가능성

특정 유형만 집중 학습하면 해당 유형의 성능은 향상되지만 전체 문장 성능이 저하될 수 있음을 확인했습니다.

따라서 일반 문장과 취약유형 데이터를 함께 학습한 모델 중 전체 성능과 요리 도메인 핵심정보 인식이 균형 잡힌 모델을 최종 모델로 선정했습니다.

## 💪 강점

- 요리 도메인에 특화된 음성 인식
- 재료명 및 조리동작 인식에 강점
- 숫자·수량·단위 데이터를 별도로 분석하고 보강
- 신규 문장을 통한 일반화 성능 검증
- TTS 출력 음성 재인식을 통한 실제 환경 평가
- 실시간 추론을 고려한 모델 경량화

## ⚠️ 한계

- 긴 문장에서 일부 단어가 누락되거나 다르게 인식될 수 있음
- 발음이 유사한 요리명과 재료명 구분에 한계가 있음
- 숫자·수량·단위가 항상 완벽하게 인식되지는 않음
- 주변 소음과 발화 속도에 따라 결과가 달라질 수 있음
- 문장 전체가 완전히 일치하지 않는 경우가 있음

## ⚡ 실시간 추론 및 경량화

학습용 모델과 실시간 추론용 모델을 구분하여 관리합니다.

```text
파인튜닝 모델
→ 배포용 형식 변환
→ 경량화
→ faster-whisper 기반 실시간 추론
```

이를 통해 파인튜닝 모델을 실시간 음성 입력 환경에 적용할 수 있도록 구성했습니다.
