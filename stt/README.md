# 🔊 ChefEar STT

ChefEar 음성 레시피 서비스에 적용하기 위해 개발한 개인 STT 모델입니다.

요리 중 화면이나 키보드를 조작하기 어려운 상황에서도 요리명, 재료명, 수량, 단위, 조리동작을 음성으로 인식할 수 있도록 Whisper 기반 음성 인식 모델을 요리 도메인에 맞게 파인튜닝했습니다.

## 🧑‍💻 담당 업무

- Whisper Small, wav2vec2, Whisper Large-v3-turbo 모델 비교
- Whisper Large-v3-turbo 기반 QLoRA 파인튜닝
- 요리 도메인 음성 데이터 전처리 및 학습
- Fixed100·신규500 데이터셋 기반 평가
- WER·CER 기반 성능 비교
- 숫자·수량·단위 취약유형 분석
- 재료명·조리동작·긴 문장 인식 성능 분석
- 파인튜닝 전후 모델 비교
- 최종 STT 모델 선정
- TTS 음성의 STT 재인식 테스트
- CTranslate2 및 faster-whisper 기반 추론 경량화

## 🎯 개발 목표

일반적인 음성 인식뿐 아니라 요리 서비스에서 중요한 다음 정보를 정확하게 인식하는 것을 목표로 했습니다.

- 요리명
- 재료명
- 재료의 수량
- 계량 단위
- 조리동작
- 조리 단계 진행 명령
- 긴 조리 안내 문장

특히 요리 서비스에서는 문장 전체가 완벽하게 일치하지 않더라도 재료명, 조리동작, 수량과 같은 핵심 정보가 정확하게 전달되는 것이 중요하다고 판단했습니다.

## 🧠 기반 모델 선정

Whisper Small, wav2vec2, Whisper Large-v3-turbo를 비교한 뒤 한국어 음성 인식 성능과 요리 도메인 문장에 대한 확장성을 고려하여 Whisper Large-v3-turbo를 최종 기반 모델로 선정했습니다.

모델 선정 과정에서는 다음 항목을 함께 비교했습니다.

- 전체 음성 인식 성능
- 요리명 및 재료명 인식
- 숫자·수량·단위 인식
- 조리동작 인식
- 긴 문장 처리 성능
- 신규 문장에 대한 일반화 성능
- 실시간 추론 적용 가능성

## ⚙️ QLoRA 파인튜닝

Whisper Large-v3-turbo에 QLoRA 방식을 적용하여 요리 도메인 음성 인식 성능을 개선했습니다.

학습 데이터에는 다음과 같은 음성 표현을 포함했습니다.

- 요리명 발화
- 재료명 발화
- 숫자 및 수량 표현
- 계량 단위 표현
- 조리동작 표현
- 단계 진행 명령
- 긴 조리 안내 문장
- 발음이 유사한 요리명 및 재료명
- 숫자·단위가 포함된 복합 문장

QLoRA를 사용하여 제한된 GPU 환경에서도 효율적으로 파인튜닝을 진행하고, 일반 음성보다 요리 도메인에 필요한 표현을 집중적으로 학습했습니다.

## 🔬 모델 개선 과정

모델 개발은 다음 순서로 진행했습니다.

```text
기반 모델 비교
→ 파인튜닝 설정 비교
→ Epoch별 성능 평가
→ 오류 유형 분석
→ 취약유형 데이터 보강
→ 숫자·단위 특화 실험
→ 일반 데이터와 보강 데이터 혼합학습
→ 최종 모델 선정
```

### 학습 설정 비교

여러 파인튜닝 설정을 비교하여 요리 도메인 음성 인식에 적합한 학습 방향을 확인했습니다.

### Epoch별 일반화 평가

동일한 학습 조건에서 Epoch별로 Fixed100과 신규500의 성능을 비교하여 과적합 여부와 일반화 성능을 확인했습니다.

### 오류 유형 분석

신규 문장 평가 결과를 분석하여 다음과 같은 취약유형을 확인했습니다.

- 숫자·수량·단위
- 긴 문장
- 받침 및 발음
- 재료명
- 조리동작

### 데이터 보강

오류가 많이 발생한 유형을 중심으로 학습 데이터를 보강하여 모델의 요리 도메인 적응력을 높였습니다.

### 혼합학습

특정 유형만 집중적으로 학습했을 때 전체 문장 성능이 일부 저하될 수 있음을 확인했습니다.

이를 보완하기 위해 일반 문장과 취약유형 데이터를 함께 학습하는 혼합학습을 적용하여 전체 성능과 도메인 핵심정보 인식 사이의 균형을 조정했습니다.

## 🧪 평가 방법

### Fixed100

고정된 100개 문장을 사용하여 모델의 기본적인 음성 인식 성능을 평가했습니다.

### 신규500

기존 학습 데이터와 겹치지 않는 신규 500개 문장을 사용하여 학습되지 않은 문장에 대한 일반화 성능을 평가했습니다.

### 도메인 핵심정보 평가

요리 서비스에서 중요한 다음 항목을 별도로 평가했습니다.

- 숫자·수량·단위
- 재료명
- 조리동작
- 긴 문장
- 발음이 유사한 표현

### TTS 재인식 테스트

TTS가 생성한 음성을 다시 STT 모델에 입력하여 실제 음성 출력 환경에서의 인식 결과를 확인했습니다.

```text
TTS 음성 생성
→ STT 재인식
→ 정답 문장과 비교
→ WER·CER 측정
```

## 📊 평가 지표

### WER

단어 단위 오류율입니다. 값이 낮을수록 단어 수준에서 정답과 가까운 결과입니다.

### CER

문자 단위 오류율입니다. 한국어 음성 인식 결과의 세부적인 차이를 확인하는 데 사용했습니다.

### 문장 전체 일치율

예측 문장 전체가 정답과 완전히 일치한 비율입니다.

### 핵심정보 인식 성공률

요리 수행에 필요한 재료명, 조리동작, 숫자·단위가 정확하게 인식되었는지를 평가한 지표입니다.

## ✅ 최종 모델 선정 근거

최종 모델은 단일 지표만으로 선정하지 않았습니다.

다음 항목을 종합하여 최종 모델을 결정했습니다.

- Fixed100 WER·CER
- 신규500 WER·CER
- 문장 전체 일치율
- 숫자·수량·단위 인식 성능
- 재료명 인식 성능
- 조리동작 인식 성능
- 긴 문장 처리 성능
- 특정 유형 보강에 따른 전체 성능 변화
- 실시간 추론 적용 가능성

숫자·단위 데이터만 집중적으로 학습한 모델은 해당 유형의 성능이 향상되었지만 전체 문장 성능이 일부 변할 수 있었습니다.

따라서 일반 문장과 취약유형 보강 데이터를 함께 학습한 모델 중 전체 일반화 성능과 요리 도메인 핵심정보 인식 성능이 균형 잡힌 모델을 최종 모델로 선정했습니다.

## 💪 STT 모델의 강점

### 요리 도메인 핵심정보 인식

재료명과 조리동작 인식에서 높은 성능을 확인했습니다.

- 재료명 인식 성공률: 98.31%
- 조리동작 인식 성공률: 99.54%

이는 요리 과정에서 중요한 “무엇을 사용하는지”와 “어떻게 조리하는지”를 인식하는 데 강점이 있음을 보여줍니다.

### 숫자·단위 인식 보강

요리 서비스에서 중요한 수량 및 계량 단위를 별도로 분석하고 보강했습니다.

```text
g   → 그램
kg  → 킬로그램
ml  → 밀리리터
L   → 리터
```

숫자와 단위가 포함된 문장을 별도로 평가하여 일반적인 음성 인식 결과만으로 확인하기 어려운 요리 도메인 성능을 검증했습니다.

### 신규 문장 일반화 평가

학습에 사용하지 않은 신규500 문장을 평가에 사용하여, 학습 문장을 단순히 암기한 것이 아니라 새로운 요리 문장에도 적용되는지 확인했습니다.

### 실시간 추론을 고려한 모델 경량화

파인튜닝 모델을 배포용 형식으로 변환하고 faster-whisper 기반으로 실행할 수 있도록 구성했습니다.

## ⚠️ STT 모델의 한계

### 문장 전체 완전일치의 한계

신규 문장에서는 문장 전체가 완벽하게 일치하지 않는 경우가 있습니다.

문장 일부에 오류가 있더라도 재료명과 조리동작 같은 핵심정보가 정확하게 전달되는지를 함께 확인할 필요가 있습니다.

### 숫자·단위 인식 오류 가능성

숫자·단위 인식 성능은 개선되었지만 모든 수량과 단위를 완벽하게 인식하지는 못합니다.

발음이 불분명하거나 주변 문장이 길어지는 경우 수량과 단위에서 오류가 발생할 수 있습니다.

### 긴 문장 성능 저하

짧은 명령어보다 긴 조리 안내 문장에서 일부 단어가 누락되거나 다르게 인식될 가능성이 있습니다.

### 유사 발음 인식 문제

발음이 비슷한 요리명이나 재료명은 문맥에 따라 다른 단어로 인식될 수 있습니다.

이 문제를 줄이기 위해 도메인 데이터 보강과 후처리를 적용했지만, 모든 유사 발음을 완벽하게 구분하는 데에는 한계가 있습니다.

## 🔤 음성 인식 후처리

요리 서비스에서 자주 사용되는 단위 표현을 한글 단위로 변환하는 후처리를 적용했습니다.

```text

kg  → 킬로그램
ml  → 밀리리터
L   → 리터
```

또한 숫자, 수량, 재료 표현을 보정하여 조리 명령어 처리에 필요한 핵심정보의 안정성을 높였습니다.

## ⚡ 배포용 모델 경량화

학습용 모델과 실시간 추론용 모델을 구분하여 관리합니다.

```text
학습용 파인튜닝 모델
→ 배포용 형식 변환
→ 경량화
→ faster-whisper 기반 실시간 추론
```

배포용 변환을 통해 실시간 음성 입력 환경에서 모델 로딩과 추론을 효율적으로 수행할 수 있도록 구성했습니다.
