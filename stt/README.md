# 🔊 ChefEar STT

ChefEar 음성 레시피 서비스에 적용하기 위해 개발한 개인 STT 모델입니다.

Whisper 기반 음성 인식 모델을 요리 도메인에 맞게 파인튜닝하여, 요리명·재료명·수량·단위·조리동작과 같은 핵심 정보를 음성으로 인식할 수 있도록 개발했습니다.

## 🎯 개발 목표

요리 중 화면이나 키보드를 조작하기 어려운 상황에서도 다음 음성 정보를 안정적으로 인식하는 것을 목표로 했습니다.

- 요리명
- 재료명
- 수량과 계량 단위
- 조리동작
- 조리 단계 진행 명령
- 긴 조리 안내 문장

## 🧑‍💻 담당 업무

- Whisper Small, wav2vec2, Whisper Large-v3-turbo 모델 비교
- Whisper Large-v3-turbo 기반 QLoRA 파인튜닝
- 요리 도메인 음성 데이터 전처리 및 학습
- Fixed100·신규500 데이터셋 기반 WER·CER 평가
- 숫자·수량·단위 취약유형 분석
- 재료명·조리동작·긴 문장 인식 분석
- 최종 STT 모델 선정
- TTS 출력 음성의 STT 재인식 테스트
- CTranslate2 및 faster-whisper 기반 실시간 추론 구조 적용
- 오류 유형 분석 및 후처리 방향 검토

## 🧪 실행 및 검증 범위

본 저장소는 개인 STT 모델 개발과 실험 결과를 기록한 포트폴리오용 저장소입니다.

- 파인튜닝 및 오프라인 평가: GPU 환경에서 수행
- CTranslate2 int8 변환: 팀 GPU 환경에서 수행
- faster-whisper 실시간 추론: 팀 GPU 환경에서 검증
- 개인 저장소: 코드, 실험 과정, 평가 결과 중심으로 공개
- 모델 가중치: 비공개 관리

개인 PC에 CUDA GPU가 없는 경우에도 코드 구조와 평가 자료는 확인할 수 있습니다. 실제 모델 추론을 실행하려면 CUDA GPU와 별도의 비공개 모델 접근 권한이 필요합니다.

## 🧠 기반 모델 및 파인튜닝

여러 STT 모델을 비교한 결과, 한국어 음성 인식 성능과 요리 도메인 적용 가능성을 고려하여 Whisper Large-v3-turbo를 기반 모델로 선정했습니다.

이후 요리명, 재료명, 숫자, 단위, 조리동작 및 음성 명령이 포함된 데이터에 QLoRA 파인튜닝을 적용했습니다.

학습 과정에서는 평가 결과를 바탕으로 오류 유형을 분석하고, 숫자·수량·단위와 같은 취약유형 데이터를 보강했습니다.

## 🧪 평가 방법

### Fixed100

고정된 100개 문장을 사용하여 기본 음성 인식 성능을 평가했습니다.

### 신규500

학습에 사용하지 않은 신규 500개 문장을 사용하여 새로운 문장에 대한 일반화 성능을 평가했습니다.

### 도메인 핵심정보 평가

요리 서비스에서 중요한 다음 항목을 별도로 평가했습니다.

- 숫자·수량·단위
- 재료명
- 조리동작
- 긴 문장
- 발음이 유사한 표현

### TTS 음성 재인식 테스트

TTS가 생성한 음성을 다시 STT 모델에 입력하여 실제 음성 출력 환경에서의 인식 결과를 확인했습니다.

> TTS 모델 자체의 개발과 학습은 본인의 담당 범위가 아닙니다. 본 문서에서는 TTS 출력 음성을 STT 평가에 활용한 재인식 테스트만 다룹니다.

```text
TTS 음성 생성
→ STT 재인식
→ 정답 문장 비교
→ WER·CER 측정
```

## ✅ 최종 모델 선정 기준

최종 모델은 WER·CER 수치만으로 결정하지 않고 다음 항목을 종합하여 선정했습니다.

- Fixed100 기본 성능
- 신규500 일반화 성능
- 숫자·수량·단위 인식
- 재료명 및 조리동작 인식
- 긴 문장 처리 성능
- 취약유형 보강 이후의 전체 성능
- 실시간 추론 적용 가능성

특정 유형의 성능만 높이는 모델보다 전체 문장 성능과 요리 도메인 핵심정보 인식이 균형 잡힌 모델을 최종 모델로 선택했습니다.

- 숫자·수량·단위 취약유형 별도 평가

## ⚠️ 한계

- 긴 문장에서 일부 단어가 누락될 수 있음
- 발음이 유사한 요리명과 재료명 구분에 한계가 있음
- 숫자·수량·단위가 항상 정확하게 인식되지는 않음
- 주변 소음과 발화 속도에 따라 결과가 달라질 수 있음
- 실제 사용자와 녹음 환경의 차이에 따라 성능이 달라질 수 있음

## ⚡ 실시간 추론 및 경량화

학습용 모델과 실시간 추론용 모델을 구분하여 관리했습니다.

```text
파인튜닝 모델
→ Base Model과 Adapter 병합
→ CTranslate2 형식 변환
→ int8 경량화
→ faster-whisper 기반 추론
```

CTranslate2 변환과 faster-whisper 기반 실시간 추론은 팀 GPU 환경에서 검증했습니다.

개인 PC에 CUDA GPU와 변환 모델이 없는 경우에는 모델을 직접 실행하기 어렵지만, 관련 코드와 변환 과정을 확인할 수 있습니다.

## 📌 정리

Whisper Large-v3-turbo를 기반으로 요리 도메인 음성 데이터에 QLoRA 파인튜닝을 적용했습니다.

모델 비교와 오류 분석을 통해 숫자·수량·단위와 같은 취약유형 데이터를 보강했으며, Fixed100·신규500 평가와 TTS 재인식 테스트를 통해 기본 성능과 실제 적용 가능성을 확인했습니다.

또한 파인튜닝 모델을 CTranslate2 int8 형식으로 변환하고, 팀 GPU 환경에서 faster-whisper 기반 실시간 추론을 검증했습니다.

본 문서는 ChefEar 프로젝트에서 수행한 개인 STT 모델 개발, 파인튜닝, 평가, 오류 분석 및 경량화 과정을 정리한 포트폴리오 자료입니다.
